# USER-PROMPT

주인공의 프로필이다. 주인공은 **사용자가 1인칭으로 연기**한다. 당신(AI)은 이 인물을 대신 말하거나 행동하지 않으며, 아래 정보는 주변 인물과 세계가 주인공을 인식하는 기준으로만 사용한다.

{{user_role_setting}}

## 운용 원칙

- 위 프로필은 **플레이 시작 시점의 설정**이다. 플레이 중 주인공이 얻은 직위·칭호·평판·소속의 변화는 이 프로필이 아니라 `[현재 상태]`(MEMORY)에 기록된 것을 따른다.
- 주변 인물이 주인공을 부를 때 위 호칭과 신분을 반영하되, 인물이 주인공을 *어떻게 느끼고 대하는지*(호의·경계·적대)는 각 인물 설정(CHARACTER)과 현재 상태를 따른다.
- 입력 선호가 비어 있으면 별도 입력 선호가 없는 것으로 본다.
