# 스토리 썸네일(표지) 이미지 생성 프롬프트

컴파일 요청의 장르 태그를 `<genre>`에, 컴파일 LLM이 만든 인물 외형을 `<characters>`에 끼워
이미지 생성 모델에 전달한다. `<characters>`에는 외형이 모두 채워진 인물 중 카드 순서 앞 1~2명이
들어간다. 그런 인물이 없으면 카드 첫 번째 인물을 넣어 표지에 인물이 최소 1명은 있게 하고,
빈 외형 칸은 빼고 보낸다(모델이 장르·성별에 맞게 채운다). 인물 카드가 아예 없을 때만
`없음` 한 줄이 들어간다(KNK-1047). 그 밖의 블록은 전부 고정이다.

그림체·분위기·화풍은 인물 이미지 프롬프트(`CHARACTER-IMAGE-TEMPLATE.md`)와 같다.
표지와 인물 이미지가 한 스토리 안에서 같은 작품처럼 보여야 하기 때문이다. 표지에서
달라지는 것은 인물 수(0~2명)의 처리와 포스터 구도뿐이다. 이미지 크기·비율은 프롬프트가
아니라 API 인자로 고정한다.

작성 규칙: 한 규칙은 한 블록에만 둔다(배경은 `<scene>`, 디테일 위계는 `<detail_hierarchy>`,
인체는 `<quality_requirements>`). 지시는 "무엇을 그릴지"로 쓴다 — 이미지 모델은 "넣지 않는다"
문장 속 명사도 그릴 재료로 받기 때문이다.
