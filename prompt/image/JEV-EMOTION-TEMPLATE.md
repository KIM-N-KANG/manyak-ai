# JEV 감정 추출

대상 인물의 감정 확률과 감정별 강도를 판단한다. 코드가 이미지에 사용할 감정·강도를 선택한다.

## state

- `target_character`: 대상 인물 이름.
- `recent_turns`: 이전 최대 2턴의 배열. 각 턴은 `user`(사용자 입력)와 `assistant`(AI 응답)로 구성하며 오래된 순서로 넣는다.
- `current_turn`: 이번 턴의 객체. `user`에 이번 사용자 입력, `assistant`에 완성된 AI 응답을 넣는다.

## questions

`emotion`은 그대로 사용한다. `intensity`는 neutral을 제외한 각 감정의 `{{emotion}}`·`{{description}}`을 넣어 `{emotion}_intensity` 질문으로 확장한다. 모든 질문을 한 요청에 넣으며, 각 질문은 독립적으로 대화를 읽는다.
